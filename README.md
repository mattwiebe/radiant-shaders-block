# Radiant Shaders Block

Radiant Shaders Block brings the Radiant shader collection into WordPress as a background-capable Gutenberg block with editor controls, theme color integration, and release packaging for distribution.

GitHub repository: [mattwiebe/radiant-shaders-block](https://github.com/mattwiebe/radiant-shaders-block)

## Credits

This project builds on the original Radiant shader work by Paul Bakaus.
